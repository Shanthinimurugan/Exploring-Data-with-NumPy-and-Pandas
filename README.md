# Exploring Data with NumPy and Pandas

## 📌 Overview

A practical exploration of data analysis using NumPy and Pandas in Python, covering array operations, indexing, slicing, Pandas Series, DataFrames, filtering, grouping, and data manipulation using temperature, student marks, and transaction datasets.

## 🎯 Objective

To practice fundamental data analysis techniques using **NumPy and Pandas**, including:

* Array creation and numerical operations
* Indexing and slicing
* Pandas Series creation and manipulation
* DataFrame exploration and filtering
* Grouping and aggregation
* Adding, updating, and deleting data

## 📋 Problem Statement

The project involves analyzing different datasets using NumPy and Pandas.

### NumPy

Temperature data for two weeks is analyzed by:

* Creating 1D and 2D NumPy arrays
* Inspecting shape, data type, and size
* Converting Celsius temperatures to Fahrenheit
* Finding maximum, minimum, and mean temperatures
* Performing indexing and slicing

### Pandas Series

Student marks are analyzed by:

* Creating a Series with custom rank labels
* Using index positions, `loc`, and `iloc`
* Applying boolean filtering
* Updating and removing values
* Calculating CGPA

### Pandas DataFrame

Transaction data is analyzed by:

* Creating and exploring a DataFrame
* Selecting columns and rows
* Filtering transactions based on conditions
* Finding value counts and unique values
* Grouping data by region and calculating mean amounts
* Updating transaction values
* Adding and deleting columns
* Removing rows
